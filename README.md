# Портфолио: Аналитик данных для онлайн-магазинов и маркетплейсов

Здравствуйте! Меня зовут Иван. Моя основная задача - помочь найти бизнесу скрытую прибыль и точки роста.

Мои главные принципы - это гибкость и умение говорить максимально понятно, на языке бизнеса. Я предпочитаю не просто строить графики и таблицы, разбрасываясь непонятной технической терминологией, а доносить конкретные наблюдения и давать рекомендации, которые имеют минимальные риски, но потенциально высокую награду.

### Мой стек и подход:
- **Язык:** Python (Pandas, NumPy)
- **Визуализация:** Matplotlib, Seaborn, Plotly
- **Инструменты:** Jupyter Notebook, Git/GitHub, Excel/Google Sheets
- **Методологии:** P&L (Отчет о прибылях и убытках), Юнит-экономика, ABC-XYZ анализ, Когортный анализ (Пожизненная ценность клиентов, Удержание клиентов)
- **Рабочий подход:** Работаю в логике Lean Startup (Бережливый стартап): не предлагаю сразу глобальных изменений, строю быстрые и дешевые эксперименты (А/В тесты, малые партии, тесты на одной категории), позволяющие найти возможность для улучшения бизнеса без рисков слить бюджет.

### Мои проекты

#### 1. Юнит-экономика: Сколько вы реально зарабатываете с одной продажи? Реальная прибыль с учетом возвратов
**Задача:** Оценить прибыльность каждой позиции ассортимента с учетом возвратов, найти точку безубыточности и определить риски, связанные с процентом выкупа.
**Результат:** Выявлена убыточная категория "Одежда" (маржинальность 3-6% против рыночных 25-35%). Разработан пошаговый план тестирования цен и гипотез по увеличению выкупа, который может спасти до 80% от упущенной прибыли.

#### 2. ABC-XYZ анализ: Какие товары генерируют прибыль, а какие - убытки и что с этим делать
**Задача:** Определить, какие товары генерируют основную прибыль и где скрыты риски нестабильного спроса. Предложить действия для оптимизации ассортимента с минимальными затратами.
**Результат:** Обнаружено, что 76.5% прибыли дают всего 3 товара с нестабильным спросом. Даны конкретные рекомендации по управлению запасами, масштабированию стабильных позиций и выводу убыточных.

#### 3. Когортный анализ: Какие клиенты приносят нам больше всего денег и более лояльны?
**Задача:** Проанализировать, какие клиенты возвращаются чаще и приносят больше денег. Найти точки роста для увеличения повторных продаж.
**Результат:** Выявлена "золотая жила" (клиенты марта) и "аномалия" (клиенты апреля, которые покупают много, но не возвращаются). Замечено "плато" в удержании клиентов, предложены гипотезы для повышения уровня повторных продаж.
